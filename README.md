# AudioHelper

Desktop-помощник для лекций и встреч: слушает выбранный микрофон, ведёт транскрипцию и помогает понять, что происходит сейчас.

**Статус:** зафиксированы требования и проектные решения; приложение ещё не реализовано. Команд запуска пока нет.
