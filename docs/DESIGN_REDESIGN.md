# Редизайн интерфейса SKAZ — согласованная спецификация

Статус: согласовано с пользователем (grilling-сессия, 19 решений). Исполнение — пачками, исполнитель `anthropic/claude-sonnet-5`.

Область: **только frontend/electron**. Backend не дорабатывается. Кнопки, за которыми нет бэкенда, не изобретаются.

---

## 1. Цвет и тема

Палитра: белое поле, чёрный текст, графитово-синий акцент `#20202A`.

| Токен | Light | Dark |
|---|---|---|
| `--paper` | `oklch(100% 0 0)` | `oklch(16% 0 0)` |
| `--paper-raised` | `oklch(100% 0 0)` | `oklch(20% 0 0)` |
| `--paper-sunken` | `oklch(97% 0 0)` | `oklch(12% 0 0)` |
| `--edge` | `oklch(91% 0 0)` | `oklch(28% 0 0)` |
| `--edge-strong` | `oklch(82% 0 0)` | `oklch(38% 0 0)` |
| `--ink` | `oklch(18% 0 0)` | `oklch(96% 0 0)` |
| `--ink-soft` | `oklch(42% 0 0)` | `oklch(76% 0 0)` |
| `--ink-faint` | `oklch(60% 0 0)` | `oklch(58% 0 0)` |
| `--accent` | `#20202A` | `#A4A4B2` (контрастный оттенок базы) |
| `--accent-hover` | `#20202A` | `#B8B8C4` |
| `--accent-quiet` | `accent / 0.12` | `accent / 0.18` |
| `--accent-wash` (новый) | `accent / 0.08` | `accent / 0.14` |
| `--live` | `#20202A` | `#A4A4B2` |

`--live` использует тот же графитово-синий цвет, что и интерактивный акцент: различие состояния «идёт запись» передают форма, подпись и анимация, а не второй цвет. В тёмной теме оба семантических токена получают контрастный оттенок базы, чтобы текст и элементы управления оставались читаемыми.

Тёмная тема сохраняется как **механическое зеркало** тех же токенов — отдельно не вылизывается. Оба блока (`@media prefers-color-scheme: dark` и `:root[data-theme='dark']`) держать синхронными.

`backgroundColor` окна Electron — `#ffffff`.

## 2. Бренд

- Слова **AudioHelper в интерфейсе не остаётся**. Бренд — SKAZ.
- Логотип **текстовый**, шрифт Playfair Display (`frontend/src/assets/fonts/PlayfairDisplay-Medium-latin.woff2`, SIL OFL, 23 КБ, latin, вес 500). Подключение — локальный `@font-face`, **без CDN** (приложение офлайновое).
- Токен `--font-display` используется **исключительно** для логотипа.
- Пустой экран расшифровки: **SKAZ AGENT** — `SKAZ` цветом `--ink`, `AGENT` цветом `--accent`, крупная разрядка (~0.18em).
- Внизу настроек — еле заметный `SKAZ`.
- `icon/icon.png` в интерфейсе **не используется** — только трей/иконка приложения.

## 3. Верхняя полоса

Растворяется: не панель, а зона перетаскивания ~38px без фона, границы и теней.
- Слева — пустой отступ ~78–80px под «светофор» macOS (`titleBarStyle: 'hiddenInset'`).
- Справа — название активной сессии + мелко дата/длительность. Нет сессии → пусто.
- Переименование по двойному клику, механика переиспользуется из `SessionList.tsx`.
- `-webkit-app-region: drag` на полосе, `no-drag` на интерактивных элементах.

## 4. Левая панель

- **Сверху — чипы-хештеги групп.** Группы парсятся из названия сессии: `Матан #универ` → тег `универ`. Множественные теги допустимы. Всегда есть чип «Все» со счётчиком и псевдогруппа «Без группы».
- Каждой группе — свой приглушённый оттенок в пределах палитры (бордо, глубокий синий, зелёный, серый — не радуга); цвет подхватывается точкой у сессии в списке.
- **Снизу в том же блоке** — Поиск, Настройки, `BackendPill`.
- Панель **сворачивается** до ~56px по `⌘/`: остаются только точки групп и три нижние кнопки.

Источник групп — только `title`. Нового хранилища не заводим. Когда в API появится `tags`, меняется только источник.

## 5. Поиск по материалам

Оверлей в стиле `⌘K`. Ищет по названиям сессий и по тексту **уже загруженных** сегментов — то есть по стору, без запросов к бэку. Переход к результату — через существующий `onCite` (`App.tsx`). Область поиска честно ограничена загруженным; не притворяемся, что ищем по всему архиву.

## 6. Панель записи (внизу)

Состав: транспорт · таймкод · кольцо уровня · RU/EN.

- **Индикатор голоса — дышащее кольцо** вокруг кнопки записи: радиус и толщина обводки от громкости. Речь — графитово-синяя `#20202A`; тишина — тонкое серое; клиппинг — короткая вспышка. CSS transform, без canvas.
- `dBFS` уходит в tooltip. `sustainedLow` → человеческое «Вас почти не слышно».
- **Переключатель языка RU/EN справа, активен во время записи.** Смена языка оставляет **постоянный разделитель** в ленте расшифровки: `── EN с 00:41:12 ──`. Рядом с переключателем — подсказка «применяется к новым фрагментам», гаснет примерно через минуту.
- Микрофон и экспериментальный режим **переезжают в настройки**.
- Статусные пилюли всплывают **слоем над** панелью, не двигая вёрстку (панель фиксированной высоты).
- Под панелью — тонкая **полоса прогресса расшифровки** (сколько аудио расшифровано относительно записанного).

## 7. Расшифровка

- Табы «Расшифровка / Конспект» — активный помечается **подчёркиванием**.
- **Караоке-подсветка**: звучащий при воспроизведении сегмент получает подложку `--accent-wash` + автоскролл.

## 8. Конспект

- Рендер через `react-markdown` + `remark-gfm` — **единственные новые зависимости** всего редизайна. Raw HTML запрещён (текст порождён из недоверенной расшифровки).
- Конспект **read-only**. Тулбара форматирования нет — фиктивное редактирование недопустимо.
- Панель при выделении: «Открыть в расшифровке `00:12:34`» · «Копировать» · «Спросить».
- Цитата ищется по вхождению выделенного текста в `citation.text` и обратно, затем по нормализованному совпадению слов. **Не нашли — кнопки перехода нет.**
- Процитированные места подчёркнуты графитово-синим пунктиром; подвал «Sources» сворачивается в компактную строку.

## 9. Правая панель (чат)

- Иллюстрация `materials/elements/chat_elements_girl.png` (1024×1536, непрозрачный тёмный фон) прижата к правому-нижнему углу, поверх — **CSS-маска-градиент** в прозрачность влево и вверх, лёгкая непрозрачность. Файл не обрабатывается вручную.
- **Белый полукруг большого радиуса** поверх иллюстрации, наполовину уходящий за нижний край; поле ввода чата сидит в его центре. Граница между чатом и картинкой — дуга, не линия.
- `EmptyState` заменяется короткой строкой-приглашением над полем ввода.
- Область вопроса (Auto/Recent/Start/Search/All) и окно в минутах — в **поповере за кнопкой-ярлыком, показывающей текущее состояние** (`Recent · 10м`). Область **сбрасывается на `Auto` при смене сессии**.

## 10. Настройки — пять разделов

1. **Устройство** — выбор микрофона (перенос из панели записи).
2. **Назначение моделей** — Расшифровка / Ассистент / Конспект: только провайдер + модель.
3. **Провайдеры** — список провайдеров, ключ и base_url **один раз на провайдера**; при сохранении фронт раскладывает ключ во все профили, использующие этого провайдера. Здесь же согласие на облако.
4. **Локальные модели** — `LocalModelPreparation`, скачивание/удаление.
5. **Система** — тема, экспериментальный контекстный режим, место под язык интерфейса. Внизу — еле заметный `SKAZ`.

API не меняется: бэк по-прежнему получает три профиля.

## 11. Локализация

**Отдельный этап после редизайна.** Сейчас интерфейс остаётся английским, тесты живы. Смешивать редизайн и вынос строк нельзя — иначе непонятно, что сломало тесты.

Язык **распознавания** (RU/EN в панели записи) — другая сущность, делается сразу.

## 12. Приёмка

- Тесты едут вместе с кодом: перенесённое проверяется на новом месте, исчезнувшее удаляется, новая логика покрывается.
- `npm run test` и `npm run typecheck` зелёные **после каждой пачки**.
- Чистый CSS тестами не покрывается — цвета, кольцо, маска, полукруг, шрифт оцениваются глазами.
- Просмотр — живьём через `npm run dev`.

## Порядок пачек

1. Токены, шрифт, `backgroundColor`, шапка.
2. Левая панель: теги, цвета групп, низ панели, сворачивание, `⌘K`.
3. Панель записи: кольцо, язык, переезд микрофона/режима, слой статусов, прогресс.
4. Расшифровка и конспект: подчёркивание табов, караоке, markdown, выделение.
5. Чат: маска, полукруг, поповер.
6. Настройки: пять разделов, общий ключ, миграция тестов.
