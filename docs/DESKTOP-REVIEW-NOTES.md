# Предварительные замечания оркестратора к desktop

Файл будет входом для независимого ревью; не считать исправленным без проверки.

- electron/main.ts setWindowOpenHandler сейчас передаёт любой url в shell.openExternal. Ограничить безопасными http/https и не запускать локальные/custom схемы из UI/контента.
- Permission handlers разрешают media целиком без проверки origin и audio-only; приложение требует микрофон, не камеру. Ограничить доверенным main frame и аудио.
- API IPC handlers проверяют method, но не senderFrame и не allowlist маршрутов. По возможности добавить точную границу; никогда не передавать секрет renderer-у.
- Перед утверждением о сохранности аудио проверить закрытие окна/quit во время записи и при непустой очереди. main window close на macOS не убивает backend, но уничтожает renderer и его ещё не отправленные PCM. Нужен flush либо явное предупреждение/отмена закрытия; не терять речь молча.
- История сообщений и конспект должны быть доступны агенту, а не только видны UI. Проверить follow-up «объясни это проще».
- Короткие чанки нельзя превращать в отдельные пункты конспекта: смысл должен объединяться по соседним фрагментам.
