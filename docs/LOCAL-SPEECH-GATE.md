# Локальный gate наличия речи

Это экспериментальный opt-in только для `local-whisper`. По умолчанию он выключен, поэтому
поведение установленной локальной расшифровки не меняется.

При включении полный WAV сначала ресемплируется в mono float32 16 kHz. Затем
`faster_whisper.vad.get_speech_timestamps` с установленными defaults отвечает только на вопрос,
есть ли хотя бы один речевой интервал. При отсутствии речи decoder не вызывается и возвращается
пустой список сегментов. При наличии речи тот же полный массив без вырезания, склейки или удаления
padding передаётся тому же decoder с `vad_filter=False`. Исходный captured WAV сохраняется и
остаётся доступен плееру независимо от результата gate.

## Включение и off-switch

В поддерживаемой конфигурации процесса backend добавьте переменную:

```sh
AUDIOHELPER_LOCAL_SPEECH_GATE=1
```

и запускайте приложение обычным способом. Допустимы также `true`, `yes`, `on`. Для
диагностического повтора без gate задайте `AUDIOHELPER_LOCAL_SPEECH_GATE=0` (либо `false`, `no`,
`off`) и полностью перезапустите backend. Неизвестное значение останавливает запуск с явной
ошибкой; процесс не меняет окружение самостоятельно.

Проверка точного config-wiring без запуска модели:

```sh
AUDIOHELPER_TOKEN=controlled-local-check AUDIOHELPER_DATA_DIR=/tmp/audiohelper-gate-check AUDIOHELPER_LOCAL_SPEECH_GATE=1 backend/.venv/bin/python -c 'from audiohelper.config import AppConfig; assert AppConfig.from_env(0).local_speech_gate'
```

Gate не распознаёт музыку, пение, ТВ или разных говорящих и не определяет конец предложения.
Ошибка/отсутствие VAD-зависимости возвращается как безопасная ошибка, а не как «тишина». Это не
исправление пользовательского дефекта по умолчанию: включение допустимо только для сравнения до
отдельной приёмки тихой и обрезанной в начале естественной речи.
