# Notes/цитирование: согласованный редизайн (2026-09-17)

Источник: разбор 9 проблем фронтенда, 21 решение подтверждено пользователем по одному.
Этот файл — контракт. Код, расходящийся с ним, считается багом.

## 1. Модель ссылок

**Единица ссылки — монолог + предложение.** Пассажи по паузам (`agent/context.py:group_passages`)
как единица цитирования упраздняются.

Монолог рвётся по:
- смене спикера (`speaker_number` токена),
- паузе внутри одного спикера > `MONOLOGUE_GAP_MS` (2500 мс),
- потолку длительности > `MAX_MONOLOGUE_MS` (120 с),
- потолку объёма > `MAX_MONOLOGUE_CHARS` (1500 симв).

Пороги — константы кода, не настройки. Без диаризации (`speaker_number = None`) разрывы идут
только по паузе и объёму, подпись — «Спикер не определён». Спикеров не выдумываем.

Нумерация монологов сквозная по записи и **вычисляется при показе**, в БД не хранится.

## 2. Якорь цитаты

Цитата хранит:
- `monologue_id` — стабильный id (id первого токена монолога; для архивных записей без
  токенов — id первого сегмента),
- `start_token_id` / `end_token_id` — **диапазон токенов**, не индекс предложения,
- `text` — фрагмент для человека,
- `start_ms` / `end_ms` — для плеера, вычислены в момент создания.

Правка орфографии внутри предложения ссылку не ломает. Разбиение фразы надвое — тоже.
Неразрешимый якорь (монолог пересобран после recheck) помечается устаревшим — как уже
работает `notes.stale` — и предлагает ближайшее сохранившееся место, **но не подставляет
другое молча**. Номер предложения в UI не показывается никогда; показывается сам текст фразы.

## 3. Метки в тексте

Модель по-прежнему пишет `[P…]`/`[S…]`, проверка происхождения (`_grounded`) остаётся.
Сразу после валидации метки **вырезаются**: в БД и в `.md` уходит чистый текст.
Связь живёт отдельной картой «диапазон символов в заметке → якорь».

При правке в редакторе диапазоны сдвигаются вместе с текстом. Переписанный до неузнаваемости
или удалённый фрагмент — связь отпадает молча, без попыток угадать новое место.

Подсветка цитат в тексте заметки (`citationHighlight`) убирается полностью. Блок
`Sources (N)` удаляется. Источник виден только при выделении фрагмента: есть якорь —
в панели есть «Показать в записи», нет якоря — пункта нет. Никаких бейджей «AI».

## 4. Ассистент

Тот же механизм якорей и тот же рендер ссылки («Спикер 2 · <фраза>»), метки так же
вырезаются из ответа. Отличие одно: под ответом в чате остаётся блок источников,
**свёрнутый по умолчанию**, раскрывается кликом.

## 5. Notes как редактор

- Вкладки в стиле браузера/Обсидиана заменяют селектор «Заметки сессии».
- «+» → меню: «Создать конспект с ИИ» / «Создать пустой» / «Открыть существующий»
  (поиск по заметкам **всех** сессий).
- Каждая вкладка жёстко помнит свою сессию: инструменты и «показать в записи» работают
  с транскрипцией именно её сессии, а не текущей выбранной слева.
- Набор открытых вкладок переживает перезапуск приложения.
- Меню инструментов в строке вкладок: сейчас только «Сгенерировать конспект по транскрипции»,
  доступно в любой вкладке, включая созданную пустой. Перевод/правка/стиль не показываются,
  пока не реализованы — никаких серых «скоро».
- Генерация **всегда создаёт новую вкладку**; существующий текст не трогается никогда.
- Ползунок подробности: «Тезисно / Обычно / Подробно», 3 дискретные позиции, в том же меню.
  Меняет только плотность (сколько монологов на пункт, допустимо ли несколько пунктов на
  монолог). Степень заземления не меняет: даже на «Подробно» нельзя сказать больше, чем
  сказано в монологе, и каждый пункт обязан иметь якорь. Последнее значение запоминается.
- Стартовый экран: две кнопки. «Создать пустой» активен всегда; «Создать с ИИ» неактивен
  с причиной прямо на кнопке («Нет транскрипции» / «Остановите запись»). Кнопки не прячутся.
- Сохранение: автосейв через ~2 с простоя + при закрытии вкладки, смене сессии и выходе.
  Cmd+S — явное сохранение. Неприметная кнопка = индикатор «Сохранено / Сохранение…»,
  по клику тоже сохраняет. Диалогов «сохранить изменения?» нет.

Удаляются: кнопки «Edit note», «History · 30 days», «Заменить текущую», селектор заметок.

## 6. Версии и корзина

**Версии заметок удаляются целиком**: `noteHistory`, `restoreNote`, таблица версий,
`expires_at`. Защита от потери — корзина + Cmd+Z в открытой вкладке.

Корзина — пункт внизу списка сессий:
- туда попадают удалённые сессии (с аудио и транскрипцией) и удалённые заметки;
- действия: «Восстановить», «Удалить навсегда», «Очистить корзину»;
- **автоочистки нет вообще**, никаких 30 дней;
- аудио удалённой сессии лежит на диске до очистки — занятый объём показан в заголовке корзины.

Множественный выбор сессий без отдельного «режима»: Cmd+клик — добавить, Shift+клик —
диапазон, Cmd+A — все. При выделении >1 над списком полоска «Выбрано: N» с действиями:
**Удалить (в корзину)**, **Экспорт в Markdown**, **Снять выделение**. В корзине —
«Восстановить» / «Удалить навсегда». Объединение сессий и массовая перегенерация — не делаем.

## 7. Файлы

- **Транскрипция** — производный артефакт: файл перезаписывается автоматически, без статуса
  и подтверждений. Нет файла — создаём, есть — заменяем. `SessionFilesStatus` удаляется.
- **Заметки** — документ пользователя: файл пишется при сохранении; если файл изменился на
  диске снаружи с момента нашей последней записи, мы **не** затираем его молча, а показываем
  метку во вкладке.
- Файлы конспектов — в папке сессии, имя = первый заголовок документа (иначе «Конспект N»),
  переименование заголовка переименовывает файл, коллизии разводятся суффиксом. Конспект по
  нескольким сессиям кладётся в папку той сессии, в которой была открыта вкладка.
- **Экспорт транскрипции — монологами**: блок = спикер + сплошной текст, один таймкод на
  блок (начало монолога). Посегментное хранение в БД не меняется — оно нужно плееру,
  диаризации и перепроверке.

## 8. Миграция

Миграции нет и кода автоудаления нет. Пользователь чистит базу сам:
`DELETE FROM notes; DELETE FROM messages;` (+ таблица версий, пока она существует) и удаляет
старые `.md`. Новый код не обязан читать старые заметки с метками `[P4]` в тексте.

## Этапы

1. Бэкенд: модель монологов и якорей, генерация заметок по монологам, вырезание меток. ← текущий
2. Фронтенд: редактор с вкладками, автосейв, стартовый экран, меню инструментов, ползунок.
3. Корзина, множественный выбор сессий, удаление версий.
4. Экспорт монологами, разделение правил записи файлов.
