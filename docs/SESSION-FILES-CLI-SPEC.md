# SKAZ: файловые сессии, заметки и CLI — подтверждённая спецификация

Статус: пользователь подтвердил реализацию после интервью. Это требования, не отметка готовности. Работает ASTRA самостоятельно, без coding-помощников, commit/push и платных вызовов/микрофона.

## Движки
- Assistant и Notes независимо выбирают Codex CLI, Claude Code CLI, Hermes CLI либо существующий API-провайдер. OpenAI/Anthropic API остаются.
- Отсутствующий CLI предлагается установить только по явному запросу пользователя. Вход официальный, собственными средствами CLI; SKAZ не читает/копирует чужие OAuth-токены.
- Текущая сессия — default scope. Assistant может явно получить контекст текущей папки-группы, не других групп. Более широкий обзор возможен в будущем, сейчас запрещён.
- Notes по умолчанию текущей сессии; несколько сессий только при явном выборе режима.
- Аудио хранится для ASR/плеера, не доступно текстовым движкам. Только разрешённые транскрипции/заметки; транскрипции недоверенные, обязательны таймкоды/источники.
- Нет записи файлов, shell, произвольной сети/веб-поиска. Разрешён транспорт к выбранной модели. Приложение валидирует ответ и сохраняет Notes самостоятельно.
- Read-only обеспечивается технически, не промптом. Непроверенные/несовместимые движки недоступны с причиной. Никакого небезопасного режима или молчаливого fallback.

## Soniox
Единый `provider_keys`/`provider_has_api_key`, существующий OS Keychain item сохраняется. Не добавлять отдельное шифрование. Привязка к подписанному бандлу — отдельный hardening всех провайдеров, вне среза. Сохранить off-loop I/O, остановку live-ASR при удалении ключа, приватность, consent и cancellation safety.

## Хранилище
Корень по умолчанию Documents/SKAZ, выбираемый пользователем. Корень → группа → сессия → audio/, Transcript.md, отдельные файлы Notes. «Без группы» физическая, «Все» только UI. Удаление группы переносит её сессии в «Без группы». Старые сессии разрешено удалить при переходе: без миграции и двойного старого пути. Не удалять произвольные внешние файлы.

Файлы — односторонняя проекция из приложения. Внешние изменения не импортировать и не перезаписывать молча: отдельный конфликтный файл. Атомарная запись. В БД служебное состояние и история замен.

## Запись
Record только до первой записи; затем Pause / «Продолжить запись». Можно продолжать после повторного открытия сессии. Нет вечного завершения. Пауза закрывает provider tail, затем создаёт/обновляет один Transcript.md из стабильного текста. Внутреннее сохранение аудио/состояния идёт во время записи. Проигрывание отдельно от продолжения записи.

## Notes
Только по запросу. Повторная генерация предлагает «Создать новую заметку» или «Заменить текущую». Новые заметки самостоятельные и видны списком, отдельные файлы. Замена только после успешного получения/валидации. Предыдущая версия в БД на 30 дней после замены, затем cleanup. Восстановление доступно; текущие/самостоятельные заметки cleanup не затрагивает. Ручные правки обновляют файл. Новая запись помечает устаревание Notes, не генерирует их автоматически.

## Проверки
Публичные seams из QUALITY: settings/providers, session/query, ingestion/pause/reopen, notes API и desktop UI. Негативные security tests scope/symlinks/audio/tools/network; conflict/atomic file tests; expiry/restore Notes; Soniox key omission/delete/failure/cancellation. Реальные CLI inference и ASR/микрофон не подменять fixtures; приёмка пользователя отдельно.
