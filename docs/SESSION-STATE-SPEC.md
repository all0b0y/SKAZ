# Подтверждённое расширение AudioHelper

Статус: пользователь подтвердил после пошагового grill-интервью; это требования, НЕ отчёт о реализованном. Оркестратор: gpt-6-astra / openai-codex. Backend: выбран claude-opus-5; UI: выбран Opus 4.8, фактический ID проверять при запуске. Без скрытых замен; при лимите Claude оркестратор явно продолжает сам. Не commit/push, не менять IDEA.md.

## 1. Импорт и аудио
- Один/несколько файлов через последовательную очередь, отдельная сессия на файл. Ошибка одного не останавливает остальных; ожидающие задания отменяемы.
- MP3, WAV, M4A, FLAC, OGG/Opus, WebM с аудио. Проверка содержимого и локальная конверсия до платного API; видео исключено.
- Перед платным запуском: длительность, провайдер, точный model ID, достоверная оценка стоимости или явное «неизвестна», подтверждение. Для очереди общий состав/оценка только если известны все части.
- Полноценная сессия: транскрипция/таймкоды, плеер, Session State, чат, конспект, автоматическая проверка памяти. Обращения в импортированном аудио НЕ вызывают уведомлений.
- Необязательная дата разговора отдельно от даты импорта. Неизвестная дата не позволяет автоматически заменить актуальный факт памяти.
- Собственная локальная копия аудио до удаления сессии/команды удаления только аудио. Последнее сохраняет тексты, предупреждает о потере прослушивания и повторного ASR.
- Аудио и прогресс сохраняются по частям. После сбоя предлагается продолжение, готовые результаты не запрашиваются повторно. Неопределённый статус последнего платного запроса требует предупреждения перед повтором.

## 2. Транскрипция и источники
- Любой фрагмент доступен для прослушивания и исправления, независимо от подсветки. Есть воспроизведение всей записи.
- Подсветка использует доступные ASR-сигналы и отдельно маркируемые текстовые аномалии; нет сигналов — нет вымышленной оценки уверенности. Повторный ASR фрагмента по действию пользователя с предупреждением о стоимости.
- Правки сохраняют оригинал, таймкод, автора пользовательской правки. Пересчитываются затронутые state/memory; существующий конспект помечается требующим обновления. Источник отмечается как отредактированный пользователем.
- Текстовые модели получают текст/структурированные данные, не аудио. Звук получает лишь ASR.
- Ссылка конспекта открывает сессию, выделяет фрагмент, устанавливает позицию аудио без автозапуска. Прямое действие прослушивания фрагмента доступно в транскрипции.

## 3. Session State, не Meeting State
- Ядро универсально: лекции, встречи, интервью, brainstorm, разговоры, смешанные сессии. Сначала события с первичными источниками; режим сегмента динамический, не запрет извлечения других событий.
- Auto по умолчанию, необязательный ручной override. Не выдавать эвристические scores за калиброванные вероятности.
- Совместно поддерживаются темы, сущности, понятия/определения/примеры/формулы/тезисы/зависимости, идеи/предложения/возражения, решения/задачи/владельцы/сроки/риски/вопросы. Экзаменационная важность — по реально сказанному.
- Сворачиваемая панель, раскрываемые источники. Обновления без уведомлений.
- Адаптивные порции завершённого текста, без запросов в тишине. Распознавание обращений не ждёт обновления state.
- Пункты можно исправить/отклонить. Ручную правку не затирать молча; не подтверждённая транскрипцией правка — пользовательская, не подтверждённый факт общей памяти.
- Фоновый анализ включён для новых сессий только после первого подтверждения моделей и передачи текста. Отключение в сессии сохраняет запись/ASR, запрещает автоматические текстовые вызовы во время И после записи, включая память. Позже явная команда анализа.
- Только аудио: не додумывать непроизнесённые схемы/формулы, явно отмечать пробелы. Экран/календарь/внимание не входят.

## 4. Проактивные подсказки
- Только прямое обращение по списку имён/ников/форм/кодовых фраз, связанное с вопросом или просьбой. Упоминание в третьем лице не триггер. Неясный адресат: «Возможно, обращаются к тебе».
- Сначала карточка «Тебя спрашивают…», после окончания вопроса контекст/ответ, веб-результат позже в ту же карточку без повторного уведомления.
- Разрешено объединять/перефразировать явно сказанное, не добавлять предположения. Существенные утверждения с источниками. Неполный ответ и нехватку данных обозначать. При отсутствии ответа — вопрос и контекст, без обязательств за пользователя.
- Автопоиск только публичной части, если ответа нет в контексте. Не передавать имена/внутренние детали в поиск; отдельное «Из интернета» со ссылками. Общие знания не доказывают внутреннюю причину сбоя.
- Карточка в приложении, вне фокуса системное уведомление без содержания разговора, звук выключен по умолчанию (можно включить).
- Цели измерения: карточка до 3s после достаточного текста ASR, ответ из контекста до 8s после конца вопроса; отдельно измерять end-to-end от звука. Для веба видимый статус, сроки не обещаны.
- Нет уведомлений просто о важности/пропущенном; внимание не определяется.

## 5. Проекты и память
- Папка = проект; содержит сессии, живые и импорт. Переименование папок/сессий не меняет исходные файлы ОС. Ссылки по стабильным ID.
- По умолчанию контекст только текущей сессии. Галочка «Использовать другие чаты» выключена, при включении разрешает только тот же проект, для обычного чата И подсказок. Источник/дата видны.
- Источники общей памяти: транскрипции и подтверждённые ими сведения; не переписки пользователя/ИИ как независимые факты.
- После завершения модель Session State финально сверяет кандидатов с транскрипцией, учитывает исправления. Операция видна в журнале. Факты/решения/задачи отделены от предположений/открытых вопросов. Просмотр/исправление/удаление доступны.
- Новое явное решение заменяет актуальное значение с историей; предположение не заменяет, неоднозначное противоречие показывает оба источника.
- Удаление сессии удаляет производные данные/её память. Независимо подтверждённые факты остаются с другими источниками. Экспорты/Obsidian не удаляются.
- Перенос в другой проект переносит её память и прекращает доступ старого проекта. Ранее сохранённые ответы/конспекты не переписываются; предупреждение перед переносом.

## 6. Конспекты, MD, Obsidian
- В приложении конспект со ссылками. Экспорт MD/Obsidian: «С источниками» или «Чистый текст». Это НЕ загрузка стороннего MD.
- Кастомная инструкция меняет структуру/язык/стиль/подробность, не добавляет сведения извне. Чистый экспорт убирает ссылки, не достоверность.
- Экспорт с источниками: название сессии, таймкод, deep link в AudioHelper; без приложения читаемый ориентир остаётся.
- Однократный выбор локального vault и подпапки Obsidian; кнопка сохранения MD, выбор имени/источников, без молчаливой перезаписи. Без аккаунта/плагина/двусторонней синхронизации.

## 7. Чат и языки
- «Вся запись»: доступ ко всей сессии через state и первичные фрагменты, не обязательная полная отправка одним запросом. Исчерпывающие вопросы требуют проверки всей сессии, не top-k под видом полноты.
- Панель контекста сворачивается без сброса; компактно видны окно, другие чаты, проект.
- «Что я пропустил?» выбирает 2/5/10 минут или свой интервал, источники обязательны; старый контекст лишь для пояснения.
- Язык аудио: выпадающий список Auto + поддерживаемые ASR языки. Отдельный язык ответа/конспекта: как в записи или конкретный язык. Язык интерфейса не меняется.

## 8. Провайдеры, модели, журнал
- Четыре текстовых назначения: чат, конспект, Session State (включая финальную память), подсказки. Можно явно назначить одну модель всем. ASR отдельно.
- Каталог подключённого провайдера, поиск по названию/точному ID. Для текстовых задач исключать модели без текстового output (изображения-only/аудио-only/видео-only), а не фильтровать по названию. Мультимодальные с текстовым output допустимы.
- Заведомо несовместимые недоступны с причиной; непроверенные выбираемы с маркировкой. Каталог не доказывает работоспособность.
- Нет автоматической подмены. Ограниченные повторы только временных ошибок; остальные сразу объясняются. Кнопки повторить/выбрать другую модель.
- Исходные пользовательские ориентиры проблем, НЕ проверенные ID: `openrouter/deepseek v4 flash`, `openrouter/gpt-4`, `openrouter/freetouyer`, `openrouter/nvidea-nemotron` (платная). Не нормализовать/угадывать ID, установить фактические по безопасной диагностике.
- Постоянные логи только технические: операция, провайдер, exact model ID, длительность, статус/код, повторы, usage если дан. Ни транскрипций, ни запросов/ответов, ни секретов; ошибки очищать. UI строка состояния с раскрываемыми деталями.
- OpenAI/Anthropic вход по аккаунту без ручного ключа только если официально разрешён для стороннего приложения. Иначе API и честное ограничение. Не заимствовать чужие токены.

## 9. Реализация и приёмка
Порядок: надёжность моделей и аудио → конспекты/экспорт → state → память → проактивность. Старые дефекты из HANDOFF не объявлять решёнными.

Реальные API-тесты: общий лимит **$3**, после исчерпания/невозможности безопасно вместить следующий тест остановить платные вызовы, коротко сообщить результат и спросить увеличение; локальные тесты продолжаются. Неизвестную стоимость согласовать отдельно. Не считать лимит автоматически повышенным.

Публичная реальная человеческая RU/EN речь, лекционный и диалоговый материал, реальное имя из фрагмента для триггера. Не synthetic/mock как доказательство качества. Физический микрофон только с отдельным непосредственным согласием.

Проблемные модели: реальные chat И notes запросы, смысл/источники/отказ при недостатке данных. Баланс/права/недоступность — блокер, не pass. Фактические IDs/usage/задержки фиксировать, бюджеты не смешивать с заявленной стоимостью разработки.

Тесты на публичных границах по QUALITY.md; независимый review, backend/frontend gates и desktop smoke. Каждый завершённый срез отражать в HANDOFF/STATUS; подтверждение спецификации не является приёмкой реализации.
