## Зачем SKAZ

Вы отвлеклись на две минуты на лекции — а лектор уже о другом. На встрече назвали
ваше имя, а вопроса вы не услышали. Записать всё и пересмотреть потом — не помогает
*сейчас*.

SKAZ создан для этого момента. Он работает на вашем Mac рядом с разговором и ведёт
запись сказанного с таймкодами и поиском, поэтому можно спросить **«что я пропустил?»**
и за секунды получить ответ со ссылками на точные слова.

Главное правило SKAZ: **он не выдумывает того, чего не говорили.** Если в записи нет
ответа, SKAZ так и скажет, а всё, что модель добавляет из общих знаний, отделено от
того, что действительно прозвучало.

## Возможности

**🎙️ Живая транскрипция**
Потоковое распознавание речи с выбранного микрофона. Речь собирается в монологи по
спикерам (A → B → A) и читается как разговор, а не сплошной поток слов.

**🌍 Перевод в реальном времени**
Выберите ожидаемые языки — перевод появляется рядом с речью по ходу разговора.
Оригинал всегда в один клик.

**💬 Вопросы по записи**
Спрашивайте во время сессии или после: *«Что я пропустил?»*, *«Как определили X?»*,
*«Что решили по бюджету?»*. Поиск по одной сессии, группе или всей библиотеке. Ответы
содержат сноски, ведущие прямо в транскрипцию.

**📝 Конспекты, привязанные к источнику**
Структурированный конспект по транскрипции. Каждый пункт связан с речью, из которой
он взят, а SKAZ отмечает конспекты, отставшие от продолжающейся записи. Редактор
Markdown во вкладках — в стиле Obsidian.

**📂 Библиотека в обычных файлах**
Сессии объединяются в группы и могут зеркалироваться в выбранную папку как читаемый
Markdown — для Obsidian, git или поиска Finder.

**📥 Импорт записей**
Загрузите готовый аудиофайл — и получите ту же транскрипцию, вопросы и конспекты,
что и для живой сессии.

**🧩 Свои модели**
Модель выбирается отдельно для каждой задачи: транскрипция, ассистент, конспекты и
поиск. Поддерживаются Soniox (речь), OpenRouter, OpenAI и Anthropic. Никакой скрытой
подмены: если модель не подходит для задачи, SKAZ об этом скажет.

## Приватность по умолчанию

- **Без аудиоархива.** Аудио передаётся на распознавание и не сохраняется — SKAZ
  хранит текст, а не запись.
- **Всё локально.** Транскрипции, конспекты и чаты остаются на вашем Mac. Текст
  уходит только к провайдеру, которого вы сами настроили.
- **Ключи на устройстве.** API-ключи хранятся зашифрованными в папке данных
  приложения с правами только для владельца — не в репозитории, логах или интерфейсе.
- **Закрытый бэкенд.** Python-бэкенд слушает только loopback и требует новый
  случайный токен при каждом запуске.
- **Речь — данные, а не команды.** Услышанный текст никогда не воспринимается как
  инструкция ассистенту.

## Как это устроено

```
 Микрофон ──► Electron main ──► Python backend ──► Распознавание речи (Soniox)
                   │                  │
                   │                  ├──► SQLite + Markdown-библиотека
                   ▼                  └──► Языковые модели (ассистент, конспекты)
            React-интерфейс
```

| Слой | Технологии | Ответственность |
|---|---|---|
| Оболочка | Electron | Окно, разрешения микрофона, безопасный IPC, жизненный цикл бэкенда |
| Интерфейс | React + TypeScript, Zustand, CodeMirror 6 | Запись, транскрипция, ассистент, конспекты, настройки |
| Бэкенд | Python 3.11+, FastAPI, SQLite | Поток аудио, распознавание, библиотека, ассистент, конспекты |

## Быстрый старт

> SKAZ на ранней стадии разработки и рассчитан на **macOS на Apple Silicon**.
> Другие платформы не проверялись.

**Нужно:** Node.js 20.19+, Python 3.11+, [uv](https://docs.astral.sh/uv/) и API-ключ
хотя бы одного поддерживаемого провайдера.

```bash
# 1. Установить зависимости
npm install
uv sync --project backend

# 2. Запустить приложение в режиме разработки
npm run dev
```

При первом запуске откройте **Settings → API keys**, добавьте ключи, выберите языки,
на которых говорите, и нажмите **Record**.

### Полезные команды

| Команда | Что делает |
|---|---|
| `npm run dev` | Запуск с горячей перезагрузкой |
| `npm test` | Unit-тесты фронтенда (Vitest) |
| `npm run typecheck` | Проверка типов TypeScript |
| `uv run --project backend pytest` | Тесты бэкенда |
| `npm run dist:mac` | Сборка `SKAZ.app` и DMG — см. [Packaging](../PACKAGING.md) |

## Статус проекта

SKAZ — рабочий прототип в активной разработке. Живая транскрипция, перевод,
ассистент, конспекты, группы сессий и импорт уже работают локально. Впереди:

- [ ] Подписанные и нотаризованные релизные сборки
- [ ] Ассистент, пошагово читающий всю библиотеку
- [ ] Ручная правка спикеров
- [ ] Надёжная обработка сна, выхода и потери сети в длинных сессиях

До первого релиза возможны шероховатости и несовместимые изменения.

## Название

*Сказ* — повествование, ведущееся голосом самого рассказчика. Репозиторий сохраняет
рабочее имя `AudioHelper`.
