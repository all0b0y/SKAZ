# Agent marks

Used only to name the agent the user picks (nominative use). Trademarks belong to their owners.

- `codex.svg` — Codex mark (OpenAI), from lobe-icons `@lobehub/icons-static-svg` 1.95.1, MIT licence (https://github.com/lobehub/lobe-icons).
- `claude-code.svg` — Claude Code mark (Anthropic), same source and licence.
- `hermes.png` — Hermes Agent icon (Nous Research), rendered at 128 px from `assets/icon-master.svg` of https://github.com/NousResearch/hermes-agent (MIT).
- `opencode.svg` — OpenCode mark (the OpenCode project), the `favicon-v3.svg` served by the embedded web UI of OpenCode 1.17.18 (MIT, https://github.com/sst/opencode); outer wrapper and theme style removed.
