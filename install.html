Install SKAZ

Requires Apple Silicon Macs running macOS 13 or later. There is no Intel Mac, Windows, or Linux build.

Install via Terminal

Open Terminal, paste this command, and press Return.

curl -fsSL https://raw.githubusercontent.com/all0b0y/SKAZ/main/install.sh | bash

The installer downloads the latest stable release, verifies the checksum and SKAZ signature, then installs and opens the app. Read the installer script.

SKAZ is in early access and is not notarized by Apple. If upgrading, back up your SKAZ library and profile before opening the new version.

Install from a disk image instead

Download SKAZ 0.3.2 (.dmg)

Download from GitHub Releases. SHA-256 checksums

  1. Open the DMG and drag SKAZ into Applications.
  2. Open SKAZ from Applications. If macOS can’t verify it, click Done, then go to System Settings → Privacy & Security → Open Anyway for SKAZ. Leave the system-wide security settings on.

On first launch, choose an agent and connect your own account. Provider terms and charges may apply.
