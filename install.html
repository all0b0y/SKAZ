Install SKAZ

SKAZ 0.3.2 is an early-access release for Apple Silicon Macs running macOS 13 or later. There is no Intel Mac, Windows, or Linux build.

Download SKAZ 0.3.2 (.dmg)

Download from GitHub Releases. SHA-256 checksums

Set up the app

  1. Open the DMG and drag SKAZ into Applications.
  2. Open SKAZ from Applications. If macOS can’t verify it, click Done, then go to System Settings → Privacy & Security → Open Anyway for SKAZ. Leave the system-wide security settings on.
  3. On first launch, choose an agent and connect your own account. Provider terms and charges may apply.

Prefer Terminal? See the official Terminal installation instructions.

This release is signed with the project’s own SKAZ certificate and is not notarized by Apple. If upgrading, back up your SKAZ library and profile before opening the new version.
